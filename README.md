# LuzioSelect · instaladores

Este repositório guarda só os instaladores do **LuzioSelect**, o app de seleção de fotos para fotógrafos de evento. O código não fica aqui.

- Site: https://select.luziocrm.com.br
- Baixar a versão mais recente para Windows 10 e 11: [LuzioSelect-setup.exe](https://github.com/devgabrielluz/luzioselect-releases/releases/latest/download/LuzioSelect-setup.exe)
- Todas as versões: [Releases](https://github.com/devgabrielluz/luzioselect-releases/releases)

Ao instalar, o Windows pode mostrar um aviso de programa desconhecido. Clique em "Mais informações" e depois em "Executar assim mesmo".
